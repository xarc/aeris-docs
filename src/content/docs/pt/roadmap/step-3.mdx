## Objetivo

Fazer o traço se deslocar continuamente pelo painel, sem intervenção do usuário.

## Instruções

1. Abra o simulador de linguagem RISC-V e ative o painel gráfico pelo botão do menu de opções.
2. No editor de texto do simulador, transcreva o programa RISC-V abaixo, monte e execute.

:::note
Abra o painel gráfico **antes** de montar o código, porque alterná-lo depois da montagem reinicia a simulação.
:::

## Pseudocódigo

O pseudocódigo abaixo é a referência de alto nível para o programa RISC-V da seção seguinte.

```
VARIAVEIS
    y, linha_base, endereco_base, cor, x, limite, endereco: INTEIRO
    cabeca, cauda: INTEIRO
    memoria: VETOR DE INTEIRO

INICIO

y <- 9
linha_base <- y * 32
endereco_base <- 0xFF000000
cor <- 0x0000F000

x <- 13
limite <- 19

ENQUANTO x < limite FACA
    endereco <- linha_base + x
    endereco <- endereco * 4
    endereco <- endereco + endereco_base
    memoria[endereco] <- cor
    x <- x + 1
FIM-ENQUANTO

cabeca <- 18
cauda <- 13

ENQUANTO VERDADEIRO FACA
    endereco <- linha_base + cauda
    endereco <- endereco * 4
    endereco <- endereco + endereco_base
    memoria[endereco] <- 0

    cauda <- cauda + 1
    SE cauda >= 32 ENTAO
        cauda <- 0
    FIM-SE

    cabeca <- cabeca + 1
    SE cabeca >= 32 ENTAO
        cabeca <- 0
    FIM-SE

    endereco <- linha_base + cabeca
    endereco <- endereco * 4
    endereco <- endereco + endereco_base
    memoria[endereco] <- cor

    ESPERAR 100    
FIM-ENQUANTO

FIM
```

## Programa RISC-V

```asm
.text
main:
    addi t0, zero, 9                # y = 9 (linha central do grid)
    slli t1, t0, 5                  # t1 = y * 32 (linha_base)
    lui  t2, 0xFF000                # t2 = 0xFF000000 (endereco_base)
    lui  t3, 0xF                    # t3 = 0x0000F000 (cor verde)

    # desenho inicial do traco: colunas 13 a 18
    addi t4, zero, 13
    addi a0, zero, 19
draw_initial:
    add  t6, t1, t4
    slli t6, t6, 2
    add  t6, t6, t2
    sw   t3, 0(t6)
    addi t4, t4, 1
    blt  t4, a0, draw_initial

    addi t4, t4, -1                 # cabeca = 18
    addi t5, zero, 13               # cauda = 13
    addi a1, zero, 32               # limite de coluna, usado nas comparacoes

main_loop:
    # apaga o pixel da cauda
    add  t6, t1, t5
    slli t6, t6, 2
    add  t6, t6, t2
    sw   zero, 0(t6)

    # avanca a cauda, voltando para 0 apos a coluna 31
    addi t5, t5, 1
    blt  t5, a1, cauda_ok
    addi t5, zero, 0
cauda_ok:

    # avanca a cabeca, voltando para 0 apos a coluna 31
    addi t4, t4, 1
    blt  t4, a1, cabeca_ok
    addi t4, zero, 0
cabeca_ok:

    # acende o novo pixel da cabeca
    add  t6, t1, t4
    slli t6, t6, 2
    add  t6, t6, t2
    sw   t3, 0(t6)

    # pausa para o movimento ficar visivel
    addi a7, zero, 32               # chamada de sistema: pausa
    addi a0, zero, 100              # tempo em milissegundos
    ecall

    jal  zero, main_loop
```

:::note
Este programa utiliza a instrução `ecall`. As chamadas de sistema suportadas pelo simulador estão listadas em [Syscalls](/aeris-docs/pt/riscv/syscalls/).
:::

## Explicação

O deslocamento usa duas referências de posição, a cabeça e a cauda, que avançam juntas a cada iteração: a cauda apaga o píxel que deixa de fazer parte do traço, e a cabeça acende o píxel para o qual o traço avança. Ao passar da última coluna, a posição volta à primeira. O desenho inicial agora é feito por um laço, em vez de blocos de código repetidos. A pausa entre as iterações é uma chamada de sistema, com o código 32 em `a7` e o tempo em milissegundos em `a0`. Como a pausa vale tempo real, o movimento permanece visível independentemente da frequência de execução configurada no simulador.
